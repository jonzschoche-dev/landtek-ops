B-1/B-5 refused or over-period → event (a)/(b) · B-2/B-3 refused → (c) · B-10 access denied → (d) · any new "all-heirs SPA"-type demand → (e) · B-8/B-9 unacted → (g, building-official non-action) · continued occupation post-B-0 → (f). Three uncured events = frustration option (term sheet §6).

## D. Capture protocol (every probe, no exceptions)

1. **Writing in, writing out**: every request written, dated, receipted (receiving stamp
   photographed same day); refusals to receive documented by courier/postmaster proof —
   the 0792 "phantom letter" lesson.
2. **Same-day corpus ingestion** of every request, receipt, response, and non-response
   memo (received copy, never draft — evidence-grade rule).
3. **The log**: one row per attempt in the Damages Ledger — date · office · officer ·
   charter/statutory basis · published period · response due · outcome · event letter.
4. **Charter citation on the face** of every request (service name + page + published
   processing time) — so lateness is self-computing.
5. **UDHA caution** [NEEDS-COUNSEL]: census and enforcement probes distinguish occupant
   classes up front; no eviction/demolition step against any underprivileged occupant
   without the RA 7279 procedure. (Teope — the Mayor's Executive Assistant — is not one.)
6. **Density discipline** (D-6): probes run on the calendar above, not more often; each
   traces to a milestone requirement. The LGU's refusals supply the volume on their own.

## E. What this schedule is, in one sentence

Twelve genuine performance attempts, each of which either **advances the mandate** (records,
areas, values, census rows — releasing tranches T2–T4) or **prices the obstruction**
(a dated event + notice + interest + a Damages-Ledger row) — the LGU chooses which,
probe by probe.
