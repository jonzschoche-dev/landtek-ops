## What blocks filing

1. **Site Development Plan signed by a PRC-licensed engineer or architect** — Stephen's LAB X drawings are not a site plan and carry no PRC signatory. This is the hard blocker.
2. LGU land-use / zoning certification and the CENRO land-classification certificate — request letters already drafted (`../AVI_ANCILLARY_REQUESTS_2026-09/`, letters 5 and 6), not yet sent.
3. Tax declaration in Allan's name (ancillary letter 3); fresh certified true copy of OCT P-1616 (letter 4).
4. Geotagged photographs — must be taken **within 30 days** of submission, so they are the last step, not the first.
5. Coordinates of the lot corners, water source, genset rating, TSF volume and project cost — blanks on pages 2, 3 and 5.
