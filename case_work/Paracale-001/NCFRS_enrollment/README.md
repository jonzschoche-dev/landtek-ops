# NCFRS Enrollment — Allan's Cooperative (Paracale-001)

NCFRS = **National Coconut Farmers' Registry System**, the Philippine Coconut
Authority's (PCA) official registry of coconut farmers. Enrollment is the gateway
to CFIDP benefits (scholarships, medical program, insurance, seedlings/fertilizer,
training). Registration is **free**; the form is marked "NOT FOR SALE".

## Provenance

Original file URL: `https://www.pca.gov.ph/images/pdf/ncfrs_form_fin.pdf`.
The live pca.gov.ph site sits behind an interactive Cloudflare human-verification
gate, so the file was retrieved 2026-09-03 from the Internet Archive's preserved
copies of that exact URL. Archive checksums (digest `B5S7F6XL…`) show the file
byte-identical on the PCA site across snapshots from 2022-10-28 through
2025-01-24 — this is the original file, not a retype. For a stamped paper
original, any PCA office or Municipal Agriculture Office hands them out free.

## Where to file (Region V)

- **PCA Region V Regional Office** — Rizal St., Old Albay District, Sagpon,
  Legazpi City 4500 · tel (052) 742-2100 / (052) 481-0589 · regionv@pca.gov.ph
  · FB: facebook.com/pcar5bicol
- Practical route for Camarines Norte members: **PCA Provincial Office, Daet**
  or each member's **Municipal Agriculture Office** (Paracale etc.) — walk-in
  filing accepted; PCA also runs scheduled barangay mass registrations.
- Completed forms may also be emailed to **ncfrs@pca.gov.ph**.

## Each member attaches

1. Proof of farm ownership or tenancy (tax declaration, deed of sale, CLOA, etc.)
2. 2x2 photograph
3. Photocopy of valid ID with signature
