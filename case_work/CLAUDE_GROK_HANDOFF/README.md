# CLAUDE ↔ GROK HANDOFF — protocol

Internal only. Nothing in this folder is filed, sent, or shown outside. Outward acts go through Jonathan via CoS.

## Anchor rule
Claude's documents are the anchor. Grok reviews them and defers to them, unless a verified source contradicts (record page / exhibit / annex, or a statute or SC case read in full on lawphil or the SC e-library).

## Notes
- File name: `YYYY-MM-DD_GROK_TO_CLAUDE.md` or `YYYY-MM-DD_CLAUDE_TO_GROK.md` (add `_2`, `_3` for more than one a day).
- Each item has four parts: **Claim** (what the anchor document says, with file and section), **Source checked** (the exhibit/page or the authority), **Result** (confirmed / contradicted / unverified), **Fix** (the exact proposed change).
- Severity tags: CRITICAL / HIGH / MEDIUM / LOW.
- Claude replies in this same folder, item by item: ACCEPTED (with the changed file path), REJECTED (with the reason and source), or OPEN.
- Neither agent edits the other's files. Claude changes Claude's documents.
- Grok checks this folder every weekday morning.
- The case rules still apply: no fabricated facts or law, tags [INFERRED]/[VERIFY]/[CONDITIONAL], quote statutes exactly, no adjectives about people, and the exclusions list.
